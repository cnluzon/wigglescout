# Parse a scored BED file and exports a bigWig file with given chromsizes

Parse a scored BED file and exports a bigWig file with given chromsizes

## Usage

``` r
bed_to_bw(bed, bw, chromsizes)
```

## Arguments

- bed:

  BED filename

- bw:

  bigWig filename

- chromsizes:

  Vector with length of chromosomes
