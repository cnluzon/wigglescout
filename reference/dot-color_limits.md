# Calculate color limits from a value matrix and provided parameters

Calculate color limits from a value matrix and provided parameters

## Usage

``` r
.color_limits(m, zmin, zmax)
```

## Arguments

- m:

  Value matrix.

- zmin:

  Min value. Overrides percentile.

- zmax:

  Max value. Overrides percentile.

## Value

A pair of c(min, max)
