# Processes a loci and returns a GRanges object. Removes anything that is not a name field

Processes a loci and returns a GRanges object. Removes anything that is
not a name field

## Usage

``` r
.loci_to_granges(loci)
```

## Arguments

- loci:

  Either a BED file or a GRanges object

## Value

A GRanges object
