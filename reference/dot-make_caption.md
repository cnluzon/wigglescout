# Make a string to put as caption in verbose mode. Includes system date.

Make a string to put as caption in verbose mode. Includes system date.

## Usage

``` r
.make_caption(params, outcome, verbose)
```

## Arguments

- params:

  Named list with relevant parameters and their values

- outcome:

  Named values with relevant outcomes and their values

- verbose:

  Logical. If TRUE all information is printed. If FALSE returns a blank
  caption.

## Value

A caption string
