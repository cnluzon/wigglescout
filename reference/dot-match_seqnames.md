# Match seqname lists and throws the relevant warning

Match seqname lists and throws the relevant warning

## Usage

``` r
.match_seqnames(seqnamelist, show_max_shared, show_max_missing)
```

## Arguments

- seqnamelist:

  Names list to compare

- show_max_shared:

  Maximum shared references to print

- show_max_missing:

  Maximum missing references to print

## Value

TRUE if they match, FALSE if they don't
